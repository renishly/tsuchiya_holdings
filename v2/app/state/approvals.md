# Approvals (written by the student only)

The agent reads this file and never edits it. To decide on a request listed in
`state/pending_approvals.md`, add one line per decision under "Decisions" below,
starting at the beginning of the line, in the form:

APPROVE AR-YYYYMMDD-NN   (or)   REJECT AR-YYYYMMDD-NN

using the real ID from pending_approvals.md. Each approval applies to one action
only and is consumed when used. Lines above the Decisions heading are ignored.
