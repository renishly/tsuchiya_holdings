---
name: event-review
description: Decide what this run's events mean and whether anything needs doing. Use at the start of every
  review; the events and figures are in your task.
---
1. Read each event in the task. Types: manual instruction, unfinished build, step that did not complete,
   NEEDS ATTENTION item, a move of more than 3% in a watched value since the last review, daily check.
2. For a value move, compare "now" with "at the last review" in the task. Say which input moved it (price,
   peer multiple, forecast, Md) using only numbers given to you.
3. For a failed or incomplete step, decide whether one re-run is worth it (see `delegate-task`); never more than once.
4. If nothing needs doing, say so in one or two lines. Quiet is a valid outcome.
5. Write a short explanation (at most 8 lines). Never invent or recompute a number; quote the ones you were given.
