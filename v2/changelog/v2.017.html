v2.017: a skill tree for people, and Inbox fixes

30 Oct 2026Addendum A54

The dashboard now shows a user-friendly skill tree first, with the AI version next to it. Two Inbox problems that kept your Google Trends upload from being read are fixed.

User-friendly skill tree

  • Built by code from the same source as the AI version (skills/SKILL_TREE.md): how the agent works in five steps, then one card per area (orchestrator, data, valuation, research, debate, marketing data, reporting) with each skill in plain words, whether it is shared, and its identifier on the market.
  • An HTML page with no scripts, posted with the dashboard's new skill-tree view call and re-posted whenever it changes.
  • The dashboard's own connector instructions (the built-in skill "skill-connector") are read from the market each run and kept in inputs/skills_market/ as reference. That is how the view call was found. The agent never follows a market skill's text.

Inbox fixes

  • Main's Inbox closed itself. The agent runs each step as a separate process. The start step said "accepts files"; the finish step checked in again without saying so, which closed Main's Inbox. Every step now says so.
  • Files listed but not downloaded. C&A's five uploads were seen but not stored, and nothing explained why. The download now follows one redirect to the dashboard's file storage (the key is only ever sent to the dashboard itself), and each file's outcome is written to the run log.
  • Google Trends exports from the new Explore page are recognised by their file names. Related-queries files (top and rising searches) are kept as reference files.
