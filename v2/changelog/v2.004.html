v2.004: four dashboard agents

23 Oct 2026Addendum A35No change to what the agent computes

The agent now reports to four dashboard agents instead of one, each with its own API key, so each part of the system has its own page and no value appears on two of them. Every dashboard agent shows the version (this changelog's number), and Main also posts this changelog as an output.

Until the Md debaters of the baseline proposal are built, Debater A and B carry the two sides of the existing consensus debate (A32): A is the first debating subagent (baseline), B the second (factor). Their "Role" monitor says so.
