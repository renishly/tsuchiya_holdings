v2.018: the seminar's weekly Forecast and Run status

13 Nov 2026Addendum A55

The agent now sends the seminar's standard outputs: a weekly Forecast for the class's Forecasts tab, and a Run status monitor on all four dashboard agents that shows which steps worked. Shared skills now carry a market category, a scope and their dependencies.

Weekly Forecast (Main)

  • Once per ISO week, an output in the category Forecast: target "Tsuchiya Holdings (1840)", value = the Average Valuated Price (agent baseline), market = the latest stored price, in JPY.
  • View, by a fixed code rule: Overweight if the combined expected return (incl. dividend yield) is above +10%, Underweight below −10%, Neutral otherwise. No model chooses it. This replaces the earlier rule that the view was only the student's (your decision, 13 Nov 2026).
  • Why it changed is written by code: the move against last week's value and price, the method that moved most, methods not computed this week, and any change of view.
  • Evidence: links to the sources behind the price and the valuation inputs, and to the agent's data folder.

Run status (all four agents)

  • A monitor named Run status: the last run, its status (new data, no new data, failed) and a list of steps, each ok, failing or silent. The dashboard shows an agent as Needs attention when the run failed or a step is failing or silent.
  • Main: Run, Filings and IR, Market price, Peers, Valuation, Research, Debate evidence, Marketing data, Dashboard, judged from the same items as the "Data gaps and errors" report. A step fails on a high item, or on a core source that failed in this run. Lasting gaps (a method not computed, research coverage) and supporting-only sites are shown as notes. Market price and Valuation turn silent after 5 days without new data.
  • C&A: one step per evidence source (a citable source with an error fails; GDELT is context only) and the arbitration. Debater A/B: their position in the latest debate.

Connector and skills

  • New connector calls: send_forecast, set_run_status with step, debate and my_state. The run log records how the dashboard shows Main after each run.
  • Check-in intervals may now be up to 35 days (was 7). The agent still checks in every 14 hours.
  • Shared skills are posted with a market category (matched against the dashboard's category list) and a scope: common for general methods, personal for forecast-inputs, forecast-discount, universe and debater-memory. Their frontmatter now lists depends_on, which orders them on the class skill map.
  • The existing "md debate record" and "debate turns" outputs already appear in the Debate tab; they are unchanged.
