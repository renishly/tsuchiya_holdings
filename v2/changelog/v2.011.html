v2.011: old monitors removed automatically

30 Oct 2026Addendum A47

Each dashboard page now keeps only its current monitors. Monitors left over from earlier versions are deleted at the end of each run, and every removal appears in that page's activity log.

What changed

PageMonitors kept
MainOverview (read me first), Status, Version, Build phases, Rows per CSV, Pending approvals, Data (CSV files), Google Sheet, Data dictionary, Debug log, Current market price, Average valuated price, Valuation (agent baseline), Model weights, Md (forecast discount), Research (M1 and backtest), Backtest report
C&AOverview (read me first), Version, Md debate: Debate Signal, Arbitration (decision models)
Debater A and BOverview (read me first), Version, Role, Latest position
  • A monitor set during the run is always kept, even if it is not on the list.
  • Nothing is deleted when a page's monitor list cannot be read, or while the page is paused.

Checked

  • Against a local mock with old monitors on each page: the old ones were removed, current ones kept, and a page whose list could not be read was left untouched.
