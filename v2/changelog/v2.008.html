v2.008: M1 fixes, an annual backtest and readable HTML pages

30 Oct 2026Addendum A44Universe unchanged (widening it needs the student's approval)

M1's two equations are cleaned up, the backtest now judges methods on one cross-section per year, and every report and each reporting page's overview is a script-free HTML page written to be understood without the code.

What changed

ItemChangeType
M1 EV/EBITDA equationFits log(EV ÷ 3-year average EBITDA) instead of EV/EBITDA; company-years whose latest EBITDA is below half the 3-year average are left out, so one bad year no longer produces a huge multiplefix
M1 P/B equationClean ROE from ordinary profit × (1 − 30.4%) ÷ net assets, so land sales and one-off tax charges no longer move itfix
BacktestAcceptance now uses one cross-section per year (July, non-overlapping one-year returns, plain t). The monthly test (overlapping returns, Newey-West t) is kept as a reference only.updated
ApprovalsA new research run supersedes older pending parameter approvals, so only one waits at a timefix

Results on current data

  • P/B equation: clean ROE 7.02, growth −0.78; R² 0.61. Tsuchiya's fitted P/B 0.42 (80% interval 0.26–0.69).
  • EV equation (114 company-years): margin −4.37, growth 1.34, log revenue −0.10; R² 0.29. Tsuchiya's fitted EV/EBITDA 13.4 (7.7–23.3).
  • Annual backtest: 9 yearly cross-sections; no method passes (best: trailing peer P/E, rank correlation 0.13, t 1.11), so all valid methods keep equal weights. Monthly reference: trailing P/E 0.15 (t 2.41), M1 P/B 0.07 (t 1.01), M1 EV 0.04 (t 0.70).
